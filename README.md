## Selected projects

### [Hiring Capacity Lab](https://tristancouvares.github.io/hiring-capacity-lab/)

A synthetic operating model for exploring hiring demand, recruiting throughput, and backlog. Change the assumptions and see how the projected queue changes over time.

React · TypeScript · Interactive public demonstration

[Live model](https://tristancouvares.github.io/hiring-capacity-lab/) · [Source](https://github.com/tristancouvares/hiring-capacity-lab) · [Example and context](https://tristancouvares.com/work/#hiring-capacity-lab)

Every figure is created for the demo; no employer records or real performance results are represented.

### [GPT in iMessage](https://github.com/tristancouvares/gptimessages)

An early experiment connecting a language model to an existing messaging interface, with a draft-and-approval step before sending.

Python · AppleScript · Historical prototype

[Source](https://github.com/tristancouvares/gptimessages) · [Context](https://tristancouvares.com/work/#gpt-in-imessage)

Presented as an experiment, not a supported product or a current compatibility guarantee.

### [CSV Import Reshaper](https://github.com/tristancouvares/csvimport)

A command-line utility for a specific Lever-style CSV layout: combine names and locations, carry selected fields across, and generate an identifier and timestamp for each output row.

JavaScript · CSV · Data utility

[Source](https://github.com/tristancouvares/csvimport) · [Mapping example](https://tristancouvares.com/work/#csv-import-reshaper)

### [Sudoku Backtracking Solver](https://github.com/tristancouvares/sudoku-solver)

A compact recursive solver: try a digit, check the row, column, and box, then recurse—or backtrack when a branch fails.

Python · Backtracking · Algorithm study

[Source](https://github.com/tristancouvares/sudoku-solver) · [Algorithm outline](https://tristancouvares.com/work/#sudoku-solver)
